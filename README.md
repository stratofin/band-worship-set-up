# 編曲架構示意圖 ARRANGER

敬拜樂團「分軌編排 / 段落架構」視覺化工具。單一 HTML 檔、免安裝、離線可用,把一首歌的段落結構、各樂器在每段彈什麼、編排層次,一頁看清楚,並可列印成 A4 圖示譜發給團員。

作者編排概念：永鴻

---

## 快速開始

直接用瀏覽器打開 `index.html` 即可,無需安裝。

若想讓團員用網址開啟,可開 **GitHub Pages**(見下方說明)。

---

## 功能總覽

**頂部設定列**
- 曲目、Key、拍號、BPM
- 字級 **−／＋**(只縮放右側檢視區,放大不會破壞版面,範圍 10–30)
- 版面切換 **🖥 電腦 / ▦ 平板 / 📱 手機**(三段,隨時只有一個啟用)
- 存檔 / 載入(本機 localStorage)、JSON 匯入匯出、CSV、PNG、圖示譜 PDF

**左側 段落編輯**
- 每個段落:名稱、Bar 數、段落顏色、備註
- 8 種樂器:Vocal、KB、Pad、AG、EG1、EG2、Bass、Drum,逐一填入該段彈法
- 內層(layers):同一段可疊多層,代表編排堆疊 / 不同段落變化
- 段落可 **上移 / 下移** 排序、**⎘ 複製**(重複的主歌副歌不用重打)

**右側 四種檢視**
| 檢視 | 用途 |
|------|------|
| 展開示意圖 | 圓圈代表段落、內圈代表層次,旁邊列出各樂器彈法 |
| 方塊流程圖 | 橫向方塊、寬度依 Bar 數,適合看整首流程 |
| 圖示譜 | 純圖示／色塊,每頁 **4 / 6 / 8 段** 可選,可翻頁、可列印 A4 PDF |
| 文字清單 | 純文字,可貼到 Notion / 筆記 App |

---

## 顏色說明

**段落層次顏色**(段落、內層用)
- 黑 = 主要 / 基底
- 藍 = 第二層
- 紅 = 高潮
- 紫 = 特效

**樂器固定顏色**(圖示譜外框)
- 🎤 Vocal 橘　🎹 KB 黃　🌫️ Pad 紫　🎸 AG 綠
- ⚡ EG1 藍　⚡ EG2 青　⬇️ Bass 紅　🥁 Drum 粉

圖示譜中每個樂器方塊：外框＝樂器色,左側粗色條＝該層次顏色。

## 存檔與備份

- **💾 存檔 / 📂 載入**:存到瀏覽器本機(localStorage),換裝置不會跟著走。
- **↓ JSON / ↑ JSON**:匯出 / 匯入完整存檔,適合備份、換裝置、分享給別人。建議重要編排都匯出一份 `.json` 留底。
- 每次編輯會自動暫存一份到本機。

---

## 列印 / PDF

圖示譜分頁的 **🖨 列印 / 存 PDF**:A4 直式、每頁依設定 4／6／8 段,瀏覽器列印對話框選「另存為 PDF」即可發給團員或現場看譜。

---

## 部署到 GitHub Pages

1. 把這個資料夾的檔案 push 到 GitHub repo(`index.html` 一定要在根目錄)。
2. repo → **Settings → Pages**。
3. Source 選 **Deploy from a branch**,Branch 選 `main` / `/(root)`,Save。
4. 等 1–2 分鐘,會出現公開網址 `https://<帳號>.github.io/<repo>/`,直接給團員開即可。

## 技術
